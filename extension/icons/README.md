# Extension Icons

Place your icon files here:

- `icon16.png` - 16x16 pixels
- `icon48.png` - 48x48 pixels
- `icon128.png` - 128x128 pixels

For quick testing, you can:
1. Create simple colored squares using any image editor
2. Use an online icon generator like https://favicon.io/
3. Download free icons from https://www.flaticon.com/

Recommended: Use a simple email/envelope icon with the RINDA brand colors.
